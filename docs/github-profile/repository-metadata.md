## Instructions for Applying via GitHub Web UI

1. Navigate to the repository on GitHub.
2. Click the ⚙️ (cog) icon next to the "About" section on the right sidebar of the repository page.
3. Paste the **Description**.
4. Set the **Website URL** where applicable.
5. Add the recommended **Topics** one by one.
6. Click **Save changes**.
